# Fábrica Android Builds — Site comercial

Landing page institucional para apresentar a Fábrica Android Builds e captar interessados em aplicativos Android para negócios.

## Arquivos
- `index.html`: conteúdo, metadados e chamadas comerciais.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: menu mobile e ano automático.
- `assets/favicon.svg`: ícone do site.

## Visualizar
Abra `index.html` no navegador. Não requer instalação nem processo de build.

## Publicar
Hospede os arquivos em serviço de hospedagem estática, mantendo `index.html` na raiz.
